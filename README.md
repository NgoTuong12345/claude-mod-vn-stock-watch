# VN Stock Heatmap — Claude Code mod

Live Vietnam stock-market heatmap (SSI iBoard data) in a Claude Code pane, with watchlist and portfolio. No API key, no dependencies, no build step.

## Install

Clone into the Claude Code mods folder (the folder name matters: state is saved to `~/.claude/state/`, two levels up from the mod):

```bash
git clone https://github.com/NgoTuong12345/claude-mod-vn-stock-watch.git ~/.claude/mods/vn-stockmarket-heatmap
```

Restart Claude Code (or let it hot-reload), then run `/vn-heatmap`.

## Use

- Tabs: VN30, Watchlist, Portfolio. Views: by sector or by exchange.
- Type `FPT` to add a ticker, `-FPT` to remove it. On the Portfolio tab: `FPT 1000 62.4` (quantity, cost in thousand VND).
- Watchlist and portfolio persist in `~/.claude/state/vn-heatmap.json`.

## Layout

```
.claude-plugin/plugin.json   plugin manifest
hooks/                       mod source (index.tsx, treemap.ts, watch.ts, types.d.ts, hooks.json)
tests/                       self-checks (watch.check.ts, watch.test.tsx)
docs/ssi-iboard-api.md       data-source API notes
```

## Test

```bash
bun tests/watch.check.ts
```

(`.claude-plugin/types/` is generated by Claude Code for type-checking and is not committed.)
